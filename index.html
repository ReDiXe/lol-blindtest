Les morceaux de la partie

    YouTube refuse la lecture (erreur 153)

    YouTube ne lit pas les vidéos intégrées dans une page ouverte directement depuis un fichier. Il faut passer par une adresse http://localhost :

    Windows : double-clique sur lancer-blindtest.bat (placé dans le même dossier que cette page).
    Mac / Linux : dans un terminal ouvert dans ce dossier : python3 -m http.server 8765, puis va sur http://localhost:8765/blindtest-lol.html
